# ZXing1cWrapper
# ZXing1cWrapper: COM-компонента обёртка для распознавания штрихкодов в 1С

Библиотека на C# (.NET 4.0) для чтения штрихкодов из PDF-документов и изображений. Обертка над библиотеками `ZXing.Net` и `PdfiumViewer`, специально адаптированная для работы в среде 1С:Предприятие 8.

## Ключевые особенности

* **Агрессивный авто-кроп (Smart Ловушка):** Пользователю достаточно выделить штрихкод в диалоговом окне строго по контуру. Компонента сама «раздувает» зону поиска (по 20% в ширину и 10% в высоту), нивелируя любые перекосы бумаги при сканировании.
* **Каскадный 4-ступенчатый конвейер распознавания:** Вытягивает даже самые «убитые» сканы:
  1. Быстрый тест чистого кропа.
  2. In-place бинаризация по формуле люминесценции (порог 200).
  3. Апскейл x2.5 (HighQualityBicubic) + добавление Quiet Zone (белые поля) + повторная бинаризация.
  4. Инверсия цветов.
* **Прямое чтение PDF:** Рендеринг страниц в памяти без использования внешних утилит (спасибо `pdfium.dll`).
* **Точная математика:** 1С хранит только относительные координаты (доли от 0.0 до 1.0), что делает шаблоны независимыми от разрешения конкретного скана.

## Установка и регистрация

Библиотека скомпилирована под платформу **x86** для совместимости с 32-битным клиентом 1С.

1. Скачайте релизный ZIP-архив из раздела **Releases**.
2. Распакуйте в локальную папку (не сетевой диск!). Убедитесь, что `ZXing1cWrapper.dll`, `zxing.dll`, `PdfiumViewer.dll` и нативный `pdfium.dll` лежат в одной директории.
3. Зарегистрируйте компоненту с правами Администратора, используя строго 32-битный `regasm.exe`:

```cmd
C:\Windows\Microsoft.NET\Framework\v4.0.30319\regasm.exe "C:\Path\To\ZXing1cWrapper.dll" /codebase /tlb
